Stockfish.js 18

Stockfish.js 18.0.8 Lite Single-Threaded est une adaptation WebAssembly de Nathan Rugg, © 2026 Chess.com, LLC, basée sur le travail de Tord Romstad, Marco Costalba, Joona Kiiski, Gary Linscott et des autres contributeurs de Stockfish. Réseau d’évaluation de Linmiao Xu.

Dans le trainer d’ouvertures, les coups de l’adversaire sont prédéfinis par les variantes pédagogiques. Stockfish est utilisé uniquement pour l’évaluation des positions.

Dans le mode Partie libre, Stockfish choisit les coups de l’ordinateur et analyse les positions après la partie. Les deux modes utilisent le même moteur local, sans API externe.

Les noms et préfixes des variantes ont été recoupés avec le répertoire d’ouvertures Lichess (CC0). Les explications françaises ont été rédigées pour ce prototype.

Les 20 exercices tactiques et leurs parties de provenance sont issus des données publiques Lichess, sous CC0. Les liens vers chaque partie sont disponibles dans les exercices. Les commentaires français sont propres à Chess Progress. Les solutions sont vérifiées hors ligne avec Stockfish, puis stockées : aucun moteur ne choisit les réponses pendant une tactique.
